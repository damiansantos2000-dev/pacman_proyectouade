
# Pacman POO

## Integrantes
- Integrante : Damian Santos Gonzalez


## Descripción
Sistema de juego Pacman desarrollado en Python utilizando
Programación Orientada a Objetos.

El jugador controla a Pacman mediante las flechas del teclado,
recoge puntos, evita fantasmas y trata de completar el laberinto
antes de perder sus tres vidas.

El sistema incluye una interfaz gráfica con Tkinter y un ranking
persistente de los cinco mejores puntajes mediante archivos JSON.

## Estructura
- modelo.py: entidades y lógica del juego.
- persistencia.py: almacenamiento de puntuaciones.
- main.py: interfaz gráfica y controles.
- puntuaciones.json: historial generado automáticamente.

## Requisitos
- Python 3 instalado.
- Tkinter disponible en la instalación de Python.

## Ejecución
Abrir una terminal en la carpeta del proyecto y ejecutar:

python main.py

## Controles
- Flecha arriba: mover hacia arriba.
- Flecha abajo: mover hacia abajo.
- Flecha izquierda: mover hacia la izquierda.
- Flecha derecha: mover hacia la derecha.

## Conceptos aplicados
- Programación orientada a objetos.
